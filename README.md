# FAWAD SPORTS — Stable Vercel/GitHub Edition

A dependency-free, mobile-first sports store frontend for Pakistan.

## Included
- Premium dark/gold FAWAD SPORTS storefront
- Football, Cricket, Shoes, Tracksuits and Accessories collections
- Search and category filtering
- Product detail pages with size/color selection
- LocalStorage cart with quantity controls
- Cash-on-Delivery checkout
- WhatsApp order handoff to 03405049439
- Responsive mobile/tablet/desktop layout
- SEO title/description on homepage
- GitHub Pages compatible static files
- Vercel compatible with no build framework dependency

## Deploy to Vercel
Import the repository and deploy. No build command is required; the included `build` script is only a file-integrity check.

## GitHub Pages
Upload the files to a repository and enable Pages. `index.html` is the homepage.

## Important
This version prioritizes a reliable zero-dependency deployment. The admin page is a frontend demo and is **not** a secure production admin system. A real production store needs server-side authentication, database, inventory persistence, and secure image storage.
